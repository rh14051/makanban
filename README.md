# مکان‌بان 📍

اپ اندرویدی «مکان‌بان» موقعیت زندهٔ گوشی (عرض/طول جغرافیایی) و تاریخ و ساعت شمسی را از طریق بلوتوث برای **گیرندهٔ مکان‌بان** (برد الکترونیکی با ماژول بلوتوث سری) می‌فرستد تا برد همیشه به‌روز بماند.

- زبان اپ: کاتلین — پشتیبانی از **اندروید ۸ به بعد** (minSdk 26)
- رابط کاربری: تمام‌فارسی، راست‌به‌چپ، فونت **وزیرمتن**، تم روشن فیروزه‌ای **Material 3**
- فاصلهٔ ایمن رابط کاربری: محتوا هیچ‌وقت زیر دوربین سلفی یا نوار هوم نمی‌رود (مدیریت صحیح WindowInsets و Display Cutout)

## امکانات

| بخش | توضیح |
|---|---|
| 📍 موقعیت زنده | نمایش عرض/طول جغرافیایی با به‌روزرسانی خودکار هر ۲ ثانیه (GPS + شبکه، بدون نیاز به سرویس‌های گوگل) |
| 🔍 جزئیات مکان | کشور، استان، شهر، محله + دقت نشانی، ارتفاع و سرعت — با روش ترکیبی (سرویس موقعیت گوشی ← نقشهٔ آزاد آنلاین ← کش محلی) و پیام خطای واضح؛ مشکل «یک بار کار کرد و بعد فقط یک خط نشان می‌داد» حل شده است |
| 📶 اتصال بلوتوث | انتخاب از بین دستگاه‌های جفت‌شدهٔ گوشی، اتصال SPP با تلاش مجدد خودکار روی کانال ناامن |
| 📤 ارسال موقعیت | قالب `lat,lon,تاریخ شمسی,ساعت` + نمایش پاسخ ACK گیرنده |
| ⏰ ارسال تاریخ و ساعت | تاریخ شمسی و ساعت گوشی به‌صورت مجزا هم قابل ارسال است (`T,تاریخ,ساعت`) |
| 📋 گزارش تبادل | نمایش آخرین پاسخ گیرنده + شش رویداد آخر (ارسال/دریافت/اتصال) |

## انتشار روی گیت‌هاب و بیلد خودکار

۱) در گیت‌هاب یک مخزن خالی بسازید (مثلاً `makanban`).

۲) پروژه را پوش کنید:

```bash
cd makanban
git init
git add .
git commit -m "مکان‌بان - نسخهٔ اول"
git branch -M main
git remote add origin https://github.com/USERNAME/makanban.git
git push -u origin main
```

۳) بیلد خودکار شروع می‌شود (`.github/workflows/build.yml`). پس از پایان، از بخش **Actions ← اجرای انجام‌شده ← Artifacts** فایل `MakanBan-APK` را دانلود کنید.

۴) انتشار رسمی: با زدن تگ، APK امضاشده در بخش **Releases** منتشر می‌شود:

```bash
git tag v1.0.0
git push origin v1.0.0
```

امضای APK: در بیلد CI یک keystore موقت با keytool ساخته می‌شود و APK ریلیز امضا می‌گردد. برای انتشار عمومی پایدار، بهتر است keystore شخصی خود را با استفاده از GitHub Secrets (مقادیر `MAKANBAN_STORE_FILE` به‌صورت Base64 و سه رمز مربوطه) جایگزین کنید.

## نصب APK روی گوشی

۱) فایل APK را از Actions یا Releases دانلود کنید و به گوشی ببرید.
۲) هنگام نصب، اجازهٔ «نصب از منابع ناشناس» را بدهید.
۳) پس از اجرا: اجازهٔ **موقعیت** و (در اندروید ۱۲ به بعد) اجازهٔ **بلوتوث** را تأیید کنید.

---

## سمت گیرنده (برد)

۱) پوشهٔ `firmware` را باز کنید و فایل `makanban_receiver.ino` را در Arduino IDE اجرا کنید (نوع برد خود را از Tools ← Board انتخاب کنید).
۲) ماژول بلوتوث سری (SPP) را طبق جدول سیم‌کشی داخل همان فایل به پورت سریال برد وصل کنید (پیش‌فرض: RX برد ۱۸، TX برد ۱۷، نرخ ۹۶۰۰ — در بخش تنظیمات اسکچ قابل تغییر است).
۳) در تنظیمات بلوتوث گوشی با ماژول جفت شوید (کد پیش‌فرض معمولاً `1234` یا `0000`).
۴) رفتار برد: با دریافت هر پیام، ال‌ای‌دی سه بار چشمک می‌زند و `OK` برمی‌گرداند؛ آخرین موقعیت و تاریخ/ساعت در حافظهٔ برد می‌ماند و روی مانیتور سری USB هم چاپ می‌شود.

### پروتکل تبادل

| جهت | قالب | مثال |
|---|---|---|
| اپ ← برد | `lat,lon,jdate,time` | `35.689200,51.389000,1405/08/10,14:30:25` |
| اپ ← برد | `T,jdate,time` | `T,1405/08/10,14:30:25` |
| برد ← اپ | پاسخ تایید | `OK` |

## مجوزهای اپ و دلیل آن‌ها

- **موقعیت (دقیق/تقریبی):** نمایش مختصات زنده و جزئیات مکان
- **بلوتوث (در اندروید ۱۲ به بعد):** دیدن دستگاه‌های جفت‌شده و اتصال به گیرنده
- **اینترنت:** فقط برای دریافت نام کشور/استان/شهر/محله از نقشهٔ آزاد آنلاین وقتی سرویس موقعیت گوشی جواب ندهد

هیچ داده‌ای به هیچ سرور دیگری ارسال نمی‌شود؛ موقعیت فقط به گیرندهٔ انتخاب‌شدهٔ خودتان می‌رود.

## سوالات متداول

**جزئیات مکان قبلاً بعد از یک بار کار دیگر نمایش داده نمی‌شد؛ الان چه فرقی دارد؟**
روش ترکیبی سه لایه است: اول سرویس موقعیت گوشی، بعد نقشهٔ آزاد آنلاین (با مهلت زمانی و زبان فارسی) و بعد کش محلی برای نقاط تکراری. اگر هر سه شکست بخورند، پیام خطای واضح نمایش داده می‌شود — نه یک خط خالی.

**برخی بردها بلوتوث داخلی ندارند؛ چه کنم؟**
در این حالت یک ماژول بلوتوث سری (SPP) به پورت سریال برد وصل کنید؛ اسکچ موجود دقیقاً برای همین حالت نوشته شده است.

**چرا موقعیت هر ۲ ثانیه به‌روز می‌شود؟**
فاصلهٔ به‌روزرسانی در `LocationEngine` روی ۲۰۰۰ میلی‌ثانیه تنظیم شده است؛ با تغییر همین عدد می‌توانید سریع‌تر یا کم‌مصرف‌تر کنید.

## نقشهٔ راه (نسخه‌های بعد)

- نمایش موقعیت روی نقشه با نشانگر زنده
- تاریخچهٔ ارسال‌ها با وضعیت ACK در حافظهٔ گوشی
- ارسال دوره‌ای خودکار هر N ثانیه با کلید روشن/خاموش
- مدیریت چند گیرندهٔ ذخیره‌شده

معماری کد (جدا بودن BtManager / LocationEngine / PlaceFinder از رابط کاربری) طوری نوشته شده که افزودن این امکان‌ها بدون دست‌زدن به بقیهٔ برنامه ممکن باشد.
